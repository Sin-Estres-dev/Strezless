# Indie Artist App - Complete Setup Guide

## What You've Built

A full-stack web application for indie artists to manage their professional music career. The app provides:

✅ **Artist Profile System** - Store all your industry identification codes  
✅ **Music Catalog Manager** - Track your releases with proper metadata  
✅ **Professional Codes Support** - IPI, ISNI, ISRC, ISWC, DDEX, UPC, UPN, EIN, UUID  
✅ **Clean, Modern Interface** - Built with Next.js, TypeScript, and Tailwind CSS  
✅ **Local Database** - SQLite for easy portability and backups  

## Quick Start (Copy & Paste)

### Step 1: Navigate to the App

```bash
cd indie-artist-app
```

### Step 2: Install Dependencies

```bash
npm install
```

This installs:
- Next.js 16.1.6 (React framework)
- Prisma (database toolkit)
- TypeScript (type safety)
- Tailwind CSS (styling)
- better-sqlite3 (database adapter)

### Step 3: Verify Database

The database is already set up! Check it exists:

```bash
ls prisma/dev.db
```

If missing, create it:

```bash
npx prisma migrate dev
```

### Step 4: Start Development Server

```bash
npm run dev
```

Visit: **http://localhost:3000**

### Step 5: Create Your First Artist Profile

1. Click **"Create Your Artist Profile"** (purple button)
2. Enter your legal name and email (required)
3. Optionally add:
   - Stage name
   - Birth date  
   - Any professional codes you have
4. Click **"Create Profile"**

### Step 6: Add Your First Track

1. From your artist profile, click **"Add Track"** (green button)
2. Enter:
   - Track title (required)
   - Duration in seconds (required)
   - Optional: Album, genre, codes
3. Click **"Add Track to Catalog"**

## Production Build

When ready to deploy:

```bash
npm run build

```

Your production app runs on port 3000.

## Understanding the Professional Codes

### Artist-Level Codes (Add to Your Profile)

**IPI Code** - Interested Parties Information
- Get from: Your PRO (ASCAP, BMI, SESAC, etc.)
- Format: 11 digits (00123456789)
- Purpose: Identifies you for performance royalties
- When: After registering as a songwriter

**ISNI Code** - International Standard Name Identifier  
- Get from: isni.org
- Format: 16 digits in 4 groups (0000 0001 2345 6789)
- Purpose: Global unique identifier for creators
- When: Once you have released work publicly

**ISWC Code** - International Standard Musical Work Code
- Get from: Your publisher or PRO
- Format: T-123.456.789-0
- Purpose: Identifies the composition/song
- When: For each original song you write

**DDEX ID** - Digital Data Exchange
- Get from: Your distributor or directly
- Purpose: Electronic data exchange with stores
- When: Setting up automated distribution

**UPN** - Universal Product Number
- Get from: Your distributor
- Purpose: Product identification
- When: Releasing an album or single

**EIN** - Employer Identification Number
- Get from: IRS (USA) or equivalent
- Format: 12-3456789
- Purpose: Tax ID for your music business
- When: Forming an LLC or hiring staff

**UUID** - Universal Unique Identifier
- Auto-generated by the app
- Purpose: Internal tracking
- When: Automatically created with profile

### Track-Level Codes (Add to Each Song)

**ISRC** - International Standard Recording Code
- Get from: Your distributor or generate yourself
- Format: Country + Registrant + Year + 5 digits (USRC17607839)
- Purpose: Identifies THIS specific recording
- When: **BEFORE distribution** (critical!)

**UPC** - Universal Product Code
- Get from: Your distributor
- Format: 12 digits
- Purpose: Identifies the product/release
- When: For albums or singles

**DDEX Metadata**
- Usually handled by distributor
- Purpose: Technical distribution data
- When: Advanced distribution setups

## API Endpoints Reference

### Artist Management

**Create Profile**
```bash
curl -X POST http://localhost:3000/api/profiles \
  -H "Content-Type: application/json" \
  -d '{
    "legalFullName": "Omar Orrantia",
    "performanceName": "Sin Estres",
    "contactEmail": "artist@example.com",
    "interestedPartyInfo": "00123456789"
  }'
```

**Get All Profiles**
```bash
curl http://localhost:3000/api/profiles
```

**Get Profile by Email**
```bash
curl "http://localhost:3000/api/profiles?contactEmail=artist@example.com"
```

**Get Profile by ID**
```bash
curl http://localhost:3000/api/profiles/PROFILE_ID
```

**Update Profile**
```bash
curl -X PUT http://localhost:3000/api/profiles/PROFILE_ID \
  -H "Content-Type: application/json" \
  -d '{
    "legalFullName": "Updated Name",
    "contactEmail": "artist@example.com"
  }'
```

### Track Management

**Add Track**
```bash
curl -X POST http://localhost:3000/api/tracks \
  -H "Content-Type: application/json" \
  -d '{
    "trackTitle": "My First Song",
    "durationSeconds": "180",
    "musicGenre": "Hip Hop",
    "intlStandardRecordingCode": "USRC17607839",
    "belongsToArtist": "PROFILE_ID"
  }'
```

**Get Tracks for Artist**
```bash
curl "http://localhost:3000/api/tracks?belongsToArtist=PROFILE_ID"
```

**Get All Tracks**
```bash
curl http://localhost:3000/api/tracks
```

## Database Management

### View Your Data (GUI)

```bash
npx prisma studio
```

Opens a web interface at http://localhost:5555

### Backup Your Database

```bash
cp prisma/dev.db prisma/dev.db.backup
```

### Reset Database (Careful!)

```bash
npx prisma migrate reset
```

This deletes all data and recreates tables.

### Update Schema

After editing `prisma/schema.prisma`:

```bash
npx prisma migrate dev --name describe_your_changes
npx prisma generate
```

## Troubleshooting

### "Cannot find module '@/generated/prisma'"

```bash
npx prisma generate
```

### "Database file doesn't exist"

```bash
npx prisma migrate dev
```

### "Build fails with type errors"

```bash
rm -rf .next
npm run build
```

### "Port 3000 already in use"

```bash
# Kill existing process
lsof -ti:3000 | xargs kill -9

# Or use different port
npm run dev -- -p 3001
```

### "Changes not appearing"

Hard refresh browser: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
