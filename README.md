> **An open-source blueprint and operational hub for modern, independent music production.**

Founded by **Sin Estres (Omar Orrantia)**, Strezless Musick Productionz is more than just a music label—it is a streamlined, scalable system for independent artists. This repository serves as our "Label OS," housing the documentation, legal templates, metadata structures, and operational resources required to build and sustain a successful music production business from the ground up.

## 📖 About

The modern music industry requires artists to be entrepreneurs. Strezless Musick Productionz is built on the philosophy of complete transparency, organized collaboration, and self-sufficiency. This repository acts as the central nervous system for our releases, ensuring that every track is properly documented, legally protected, and ready for global distribution.

## ✨ Core Capabilities

This repository equips artists and producers with the tools to:

- 📝 **Rights Management:** Standardized split sheets to track song ownership, publishing rights, and writer contributions.
- ⚖️ **Legal & Compliance:** Maintain audit-ready records for PROs (Performance Rights Organizations), publishers, and collaborators.
- 🗂️ **Asset & Metadata Organization:** Keep audio metadata, ISRC/ISWC codes, and release cataloging in one unified, queryable database.
- 🚀 **Release Strategy:** Checklists for distribution, marketing timelines, and pre-save campaigns. 
- 🤝 **Standardized Collaboration:** Provide clear frameworks for onboarding session musicians, co-writers, and engineers.

For a comprehensive breakdown of our current and future capabilities, please see [docs/CAPABILITIES.md](docs/CAPABILITIES.md).

## 🚀 Getting Started

To utilize the Strezless framework for your own projects or to contribute to our ecosystem, follow these steps:

### Installation

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/Sin-Estres-dev/Strezless.git
   ```

2. Navigate into the directory:
   ```bash
   cd Strezless
   ```

3. Explore the `/docs` folder for templates or the `/database` folder for metadata structures.

## 📂 Repository Structure

### 📑 Templates & Documents
- **Standard Split Sheet:** `/docs/splits/split-sheet-5-writers.md` — Framework for accurately dividing equity among up to 5 collaborators.
- **Distribution Checklist:** `/docs/checklists/release-prep.md` — Step-by-step guide for DSP distribution (Spotify, Apple Music, etc.).

### 🗃️ Active Catalog Data

## 💡 Innovation & Roadmap (What's Next)

We are actively evolving this repository into a comprehensive **"Label-in-a-Box"** for indie artists. Upcoming features in our roadmap include:

- [ ] **Automated Markdown to PDF:** Scripts to automatically convert markdown split sheets into signable PDF contracts.
- [ ] **Smart Contract Integration:** Exploring Web3 protocols to mint split sheets as immutable records on the blockchain.
- [ ] **Automated Metadata Generation:** Python/Node scripts that read track info and automatically format metadata for distributors like DistroKid or TuneCore.
- [ ] **Asset Folder Scaffolding:** A CLI tool that automatically generates a standardized folder structure (Stems, Masters, Artwork, Promo) for every new song project.
